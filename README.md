# [Village Kit][villagekit] UI

A React component library for Village Kit projects using [Chakra UI](chakra-ui)

[villagekit]: https://villagekit.com
[chakra-ui]: https://chakra-ui.com

## Design principles

- Playful vibes
- Functional interfaces
- Maintainable code
- Accessible HTML

## Dev

```shell
git clone git@github.com/villagekit/ui
cd ui
pnpm install
```

```shell
pnpm run dev
```
